Steady 일기

말하듯 대화하면, 따뜻하게 정리된 일기가 남아요.
질문을 따라 이야기하다 보면 오늘의 감정과 배움이 저절로 연결돼요.

⬇ 플러그인 받기 (zip) 설치 방법 보기 🛠️ 직접 만들고 싶다면

버전 0.1.0 · 약 15KB · 무료 (AI 대화 비용은 내 OpenRouter 키로 일기 한 번에 대략 100~200원)

처음이라면할 수 있는 것이렇게 저장돼요활용법 설치내게 맞게 바꾸기직접 만들기알아 둘 점

처음이라면 읽어 주세요 🙂

"플러그인"이라는 말이 낯설어도 괜찮아요. 휴대폰에 앱 하나 까는 것과 비슷해요.

📓

옵시디언이 뭐예요?

내 컴퓨터에 메모·일기를 저장하는 무료 노트 앱이에요. 글이 내 컴퓨터 안의 파일로 남아서, 회사가 사라져도 내 기록은 그대로예요. obsidian.md에서 받을 수 있어요.

🧩

플러그인이 뭐예요?

옵시디언에 기능을 하나 더 붙이는 작은 추가 기능이에요. 브라우저의 확장 프로그램이나 휴대폰 앱처럼, 넣으면 생기고 빼면 사라져요. Steady 일기는 "대화하면서 일기 쓰기" 기능을 붙여요.

⚠️

켤 때 뜨는 경고창은요?

커뮤니티 플러그인을 처음 켜면 옵시디언이 "직접 확인한 플러그인만 켜세요"라는 경고를 띄워요. 이 플러그인만이 아니라 모든 외부 플러그인에 똑같이 뜨는 안내예요.

🔒

안전한가요?

이 플러그인이 하는 일은 딱 세 가지예요. ① 내 일기 파일 읽기·쓰기 ② 대화 내용을 AI에 보내 답 받기 ③ 감정·사람 페이지 만들기. 다른 파일을 지우거나 어딘가로 몰래 보내지 않아요. 코드도 zip 안의 main.js에 그대로 들어 있어서 누구나 열어 볼 수 있어요.

↩️

마음에 안 들면요?

설정 → 커뮤니티 플러그인에서 끄면 바로 멈추고, steady-diary 폴더를 지우면 깔끔하게 사라져요. 이미 써 둔 일기는 그대로 남아요.

🙋

어려우면요?

설치는 폴더 하나 복사하고 스위치 두 번 켜는 게 전부예요. 그래도 막히면 이 페이지를 알려준 친구에게 화면을 보여 주세요.

무엇을 할 수 있나요?

빈 화면 앞에서 뭘 써야 할지 막막할 때, 대화가 일기를 대신 꺼내 줘요.

💬

질문으로 끌어내는 대화

장면 → 감정 → 몸의 느낌 → 생각 → 의미 순으로 한 번에 하나씩 물어봐요. 좋았던 일도 흘려보내지 않아요.

🫶

상담가 같은 조언

평소엔 들어주고, "어떻게 하면 좋을까?"라고 물으면 근거 있는 방법을 오늘 해 볼 수 있는 작은 행동으로 제안해요.

🧠

지난 일기를 기억해요

최근 일기를 참고해서 "지난주에도 비슷한 얘기를 했는데…"처럼 흐름을 이어서 짚어 줘요.

📝

따뜻한 요약 + 대화 원문

위에는 짧고 다정한 요약, 아래에는 Q/A 대화 원문이 그대로. 감정은 말한 그대로 남아요.

🔗

자동 링크

감정·고민·사람·장소·배운 것이 각자 페이지로 연결되고, 그 페이지에 날짜별 기억이 쌓여요.

🏷️

제목은 함께, 레슨런은 저절로

대화 끝에 오늘의 제목을 같이 정하고, 대화에서 나온 교훈은 레슨런으로 따로 모여요.

이렇게 저장돼요

왼쪽처럼 대화하고 [마치고 정리]를 누르면, 미리보기에서 고친 뒤 오른쪽처럼 저장돼요. (예시예요)

👤

사람 만나기 전 리뷰

사람 페이지를 열면 그동안 일기에 나온 이야기가 날짜순으로 쌓여 있어요. 근황, 좋아하는 것, 들었던 고민을 미리 떠올리고 가요.

✈️

여행의 좋았던 순간

여행 중이나 다녀와서 대화하면 장소 페이지에 풍경·음식·순간이 기록돼요. 몇 년 뒤에도 "거기 정말 좋았지"를 꺼낼 수 있어요.

🎓

배운 것 저장소

원데이 클래스·워크샵·책에서 배운 걸 이야기하면 배움 페이지로 연결돼요. 핵심과 "어디에 써먹을지"까지 물어봐 줘요.

🌀

반복되는 고민 보기

고민 페이지(예: 이직, 관계)를 열면 그 고민이 언제부터, 어떻게 변해 왔는지 한눈에 보여요.

💡

레슨런 모아 보기

옵시디언 검색에 tag:#레슨런을 넣으면 그동안 얻은 교훈이 있는 일기가 모여요.

🎙️

말로 쓰기

타자가 귀찮으면 음성 입력으로. 윈도우 Win+H, 맥 받아쓰기(fn 두 번), 폰은 키보드의 🎤.

시작하기

준비물은 옵시디언과 OpenRouter API 키 하나예요. 5분이면 돼요.

🔑 먼저, OpenRouter API 키 만들기

openrouter.ai 가입 → Credits에서 충전(최소 금액이면 충분) → Keys → Create Key. 이때 Credit limit(사용 한도)을 꼭 정해 두세요(예: 5달러). sk-or-로 시작하는 키는 한 번만 보이니 바로 복사해요.

  1. 플러그인 zip을 받아 압축을 풀어요. 안에 steady-diary 폴더, 설치 안내, 상담 노트 템플릿이 들어 있어요.
  2. steady-diary 폴더를 내 보관함의 .obsidian/plugins/ 안에 복사해요.
    .obsidian은 숨김 폴더예요. 윈도우: 파일 탐색기 → 보기 → 숨긴 항목 체크 · 맥: Finder에서 Cmd+Shift+. · plugins 폴더가 없으면 새로 만들어요.
  3. 옵시디언 → 설정 → 커뮤니티 플러그인 → 커뮤니티 플러그인 켜기(제한 모드 끄기).
    이때 경고창이 떠도 놀라지 마세요. 모든 외부 플러그인에 뜨는 안내예요(위 설명 참고).
  4. 설치된 플러그인 목록에서 Steady 일기를 켜요. (안 보이면 새로고침 ↻)
  5. Steady 일기 옆 ⚙️ → OpenRouter API 키를 붙여넣어요.
  6. 왼쪽 세로 막대의 📓 공책·펜 아이콘을 누르면 오른쪽에 일기 대화가 열려요. Enter 보내기, Shift+Enter 줄바꿈.

내게 맞게 바꾸기

코드를 몰라도 바꿀 수 있는 것부터, 조금 더 깊게 바꾸는 방법까지.

⚙️ 플러그인 설정에서 바로 바꾸기
  • AI 모델: Claude Sonnet 5(깊이 있게, 기본) 또는 Claude Haiku 4.5(더 저렴하게).
  • 폴더 이름: 감정·고민·사람·장소·배움 페이지가 만들어질 폴더 이름을 바꿀 수 있어요.
📅 일기 저장 위치와 이름

옵시디언 설정 → 일일 노트의 "새 파일 위치"와 "날짜 형식"을 그대로 따라요. 추천: 위치 일기, 형식 YYYY/MM/YYYY-MM-DD → 연·월 폴더로 깔끔하게 정리돼요.

🫶 상담 노트로 나만의 상담가 만들기

zip에 든 상담 노트.md를 보관함의 Steady/상담 노트.md로 넣어 두면, 일기 친구가 조언할 때마다 먼저 읽어요.

  • 나에 대해 알아 두기: "일이 많으면 미리 걱정부터 한다", "산책하면 금방 나아진다" 같은 나의 패턴.
  • 책·상담에서 배운 것: 와닿은 문장을 내 말로 몇 줄씩. 그대로 상담 방식에 반영돼요.
👤 사람 페이지를 더 쓸모 있게

사람 페이지 맨 위에 aliases: [별명, 애칭]을 적어 두면, 대화에서 별명으로 불러도 같은 사람으로 연결돼요. "좋아하는 것 · 최근 근황 · 준 선물" 같은 칸을 만들어 두면 만나기 전 리뷰가 훨씬 편해요.

📊 목록 표 만들기 (선택)

커뮤니티 플러그인에서 Dataview를 설치하면 사람·장소·배움 목록을 표로 볼 수 있어요.


✍️ 질문 방식·정리 말투까지 바꾸고 싶다면

steady-diary/main.js 안의 systemPrompt(대화할 때 규칙)와 wrapPrompt(일기로 정리할 때 규칙)에 한국어로 규칙이 적혀 있어요. 코드를 몰라도 괜찮아요.

  • Claude 같은 AI에게 main.js를 주고 "질문을 더 짧게 해 줘", "정리할 때 감사한 일 3가지를 꼭 넣어 줘"처럼 부탁하면 고쳐 줘요.
  • 고친 뒤 옵시디언에서 플러그인을 껐다 켜면 적용돼요. (진행 중인 대화는 먼저 저장!)

직접 만들고 싶다면 🛠️

Claude로 이것저것 만들어 본 분이라면, 받아 쓰기보다 직접 만들어 보는 게 더 재밌을 거예요. 구조와 프롬프트를 그대로 공개해요.

## 하는 일
옵시디언 오른쪽 패널에서 AI "일기 친구"와 대화하면, 질문을 따라 이야기하다가 마지막에 일기로 정리해서 저장해 주는 플러그인.

## 기술
- 빌드 없이 바로 쓰는 순수 JavaScript (main.js, manifest.json, styles.css 3개). 모바일 옵시디언에서도 동작하게 (isDesktopOnly: false).
- AI 호출은 옵시디언의 requestUrl로 OpenRouter API(https://openrouter.ai/api/v1/chat/completions). 모델은 설정에서 고르기 (기본 anthropic/claude-sonnet-5, 저렴한 선택지 anthropic/claude-haiku-4.5).
- API 키는 플러그인 설정 화면에서 입력, 플러그인 data에 저장.

## 대화 (오른쪽 패널)
- 메신저처럼 말풍선. 입력칸은 Enter로 보내기, Shift+Enter 줄바꿈. 한글 조합 중(isComposing)에는 보내지 않기.
- 상단에 [새 대화], [마치고 정리] 버튼. 둘 다 누르면 확인 창.
- 일기 친구 규칙: 해요체, 따뜻하게, 한 번에 질문 하나. 장면 → 감정 → 몸의 느낌 → 생각 → 의미 순으로 끌어내기.
  좋은 일도 왜 좋았는지 묻기. 평소엔 듣고 공감하되, 내가 해결책을 원하면 근거 있는 방법(인지행동치료, 행동 활성화, 수면·회복 등)을 작은 행동 1~3개로 제안.
  대화가 무르익으면 오늘 하루의 제목을 같이 정하자고 묻기. 위기 신호엔 자살예방상담전화 109, 정신건강위기상담 1577-0199 안내.
- 대화 시작할 때 최근 일기 7편(요약 부분만)을 읽어서 "지난주에도 ~했는데"처럼 이어 주기.
- 보관함의 "Steady/상담 노트.md"가 있으면 읽어서 조언할 때 우선 참고.

## 정리와 저장
- [마치고 정리]를 누르면 AI가 JSON(구조화 출력)으로 정리: title, title_options(3개), body(짧고 따뜻한 1인칭 요약, 감정은 말한 그대로),
  summary(한 줄), emotions, topics(고민), people, places, learnings(배운 것), lessons(레슨런).
- 저장 전 미리보기 창: 제목 후보 버튼, 본문 직접 수정 가능, [저장]/[취소].
- 일기 파일 위치·이름은 옵시디언 "일일 노트" 설정(.obsidian/daily-notes.json의 folder, format)을 따르기. 예: 일기/YYYY/MM/YYYY-MM-DD.md
- 노트 형식: "## 📝 제목 (시각)" → 요약 → **레슨런** 목록 → 구분선(---) → **Q.**(AI) / **A.**(나) 대화 원문.
  같은 날 다시 쓰면 아래에 덧붙이기. 속성(frontmatter)에 tags(일기, 레슨런 있으면 레슨런)와 감정 목록 넣기.
- 감정·고민·사람·장소·배움은 각각 폴더(감정/ 고민/ 사람/ 장소/ 배움/)에 페이지 하나씩. 본문에 처음 나올 때 [[이름]] 링크.
  페이지가 없으면 만들고, 맨 아래 "기억"에 "- [[날짜]] 한 줄 요약"을 덧붙이기. 이미 있는 이름·별명(aliases)은 그대로 다시 쓰기.
- 태그는 정해진 종류만 쓰고 새로 만들지 않기. 구체적인 것은 모두 링크로.

zip의 main.js를 첨부하거나 steady-diary 폴더를 연 채로 Claude에게 주세요.

첨부한 main.js는 옵시디언 일기 플러그인 "Steady 일기"야. 빌드 없이 쓰는 순수 JavaScript라서 문법은 ES2017까지만 써 줘.
대화 규칙은 systemPrompt 함수, 일기 정리 규칙은 wrapPrompt 함수와 WRAP_SCHEMA에 한국어로 적혀 있어.

나는 이렇게 바꾸고 싶어:
- (예) 질문은 더 짧고 가볍게, 반말로
- (예) 정리할 때 "오늘 감사한 일 3가지"를 꼭 넣기
- (예) 감정 페이지 말고 "운동" 페이지에도 기록이 쌓이게

바꾼 부분이 어디인지 쉽게 설명해 주고, 고친 main.js 전체를 줘.
적용은 보관함/.obsidian/plugins/steady-diary/main.js를 덮어쓰고 옵시디언에서 플러그인을 껐다 켜면 돼.
